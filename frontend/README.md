# Frontend Application: Bible Quiz Platform

Next.js App Router application built with TypeScript and Tailwind CSS.

## Features
- Next.js 16 with App Router
- Tailwind CSS v4 styling
- Centralized `apiClient` service abstraction
- Reusable UI layout and components
- Error boundary, loading, and not-found states

## Quickstart
```bash
npm install
copy .env.local.example .env.local
npm run dev
```
Accessible at: `http://localhost:3000`
